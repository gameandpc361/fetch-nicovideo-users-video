# fetch-nicovideo-users-video

GitHub actionsを用いて、特定のユーザーが投稿した動画を列挙できます。
Github actionsだとアクセスがアメリカなどになってしまいますので、日本のVPNなどを介してアクセスする必要があります。
レポジトリの設定→secrets and variables→actionsにVPN_CONFIGという名前でovpn形式のファイルをそのまま貼り付けてください。（ovpn形式のファイルの拡張子をtxtにして開き、その内容をそのまま貼り付けるだけでOK）
無料で使うなら筑波大学VPNがおすすめです。繋ぎたい中継サーバのOpen VPN設定ファイルをDLしてね
[筑波大学VPN https://www.vpngate.net/ja/](https://www.vpngate.net/ja/)
ChatGPT使ってます
